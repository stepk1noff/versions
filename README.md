# versions

Файлы версий сборки LarpLand. Лаунчер читает их напрямую по raw-ссылкам и сравнивает с тем, что установлено у игрока.

| Файл | За что отвечает |
| --- | --- |
| `launcher_version.txt` | Версия лаунчера. Если она новее установленной, лаунчер предлагает обновиться и качает `LarpLand.exe` из релиза [stepk1noff/LarpLand](https://github.com/stepk1noff/LarpLand/releases/tag/main). |
| `modpack_version.txt` | Версия модпака. Если она новее, кнопка запуска превращается в «ОБНОВИТЬ», и лаунчер перекачивает `release.zip` из релиза [stepk1noff/modpack](https://github.com/stepk1noff/modpack/releases/tag/main). |
| `discord_app_id.txt` | Идентификатор приложения Discord для статуса «В лаунчере». Пустой файл значит, что статус выключен. |

Версия это дата выпуска в виде `yyyy.MM.dd`. Второй выпуск за день получает суффикс: `2026.09.19hotfix` или `2026.09.19v2`, `2026.09.19v3`. В интерфейсе лаунчера та же версия показывается как `19.09.26`.

Порядок выпуска: сначала залить новый файл в релиз, и только потом поднять версию здесь. Иначе часть игроков получит обновление, которого ещё нет.

Файлы сохранять в UTF-8 без BOM и без перевода строки в конце.

## Как обновить модпак

1. Собрать `release.zip`: внутри архива сразу `mods`, `config`, `resourcepacks`, `servers.dat`, `options.txt` - без общей папки вокруг них.
2. Залить архив в релиз `main` репозитория `modpack`, заменив старый.
3. Поставить в `modpack_version.txt` сегодняшнюю дату в виде `2026.09.19`.

Что лаунчер делает у игрока после этого: полностью заменяет `mods`, `config` и `resourcepacks`, а `servers.dat` и `options.txt` оставляет игроку - они ставятся из архива только тем, у кого их ещё нет. Настройки игры из сборки игрок может получить вручную: «Перекачать сборку» → согласиться на перекачку → согласиться на сброс настроек.

## Как включить статус в Discord

1. Открыть <https://discord.com/developers/applications>, нажать **New Application**, назвать `LarpLand`.
2. На вкладке **General Information** скопировать **Application ID** - это длинное число.
3. На вкладке **Rich Presence → Art Assets** загрузить картинку статуса и назвать её ровно `rpc_icon`.
4. Положить скопированный идентификатор в `discord_app_id.txt` этого репозитория, одной строкой, без пробелов.

Лаунчер прочитает файл при следующем запуске и включит статус сам, новая версия лаунчера для этого не нужна.
